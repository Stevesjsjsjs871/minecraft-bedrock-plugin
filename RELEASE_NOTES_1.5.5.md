# Minecraft Bedrock Engineer 1.5.5

This maintenance release makes the Skills-only architecture consistent across the primary authoring, validation, visual-resource, Creator Tools coordination and release workflows. It adds a dedicated maintenance skill, replaces stale calls to unavailable tools with real-capability/fallback procedures, and removes obsolete Cloudflare deployment scaffolding and generated bytecode caches. Reusable algorithms, references, sample assets and tests are retained for dependency-aware migration.

Validation scope: package metadata and the candidate archive must be checked after Plugin Creator accepts the update. Minecraft runtime, Blockbench interoperability and any test suite not actually executed remain `NOT RUN`.
