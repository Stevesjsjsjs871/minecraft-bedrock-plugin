# Compatibility notes

Minecraft Bedrock formats and Script API capabilities can vary by game version and platform.

When requesting help, provide the exact Minecraft Bedrock version/build and state whether you use Stable or Preview. Include the declared `@minecraft/server` dependency and other module versions when Script API compatibility matters.

This repository does not claim a complete compatibility matrix. Add a version to a tested list only after an actual test has been performed and recorded, including platform and relevant pack details.
