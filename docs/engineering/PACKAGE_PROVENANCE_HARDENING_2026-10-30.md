## Selected task

Make package integrity a fail-closed release gate and add a deterministic Skills-only archive builder. The gate must reject generated Python bytecode/cache directories, symlinks, special files, missing or tampered provenance, mismatched versions and changes to the original three default prompts.

## Implementation

- Added package_provenance.py:
  - no-follow filesystem inventory;
  - rejection of symlinks, special files, __pycache__, .pyc and .pyo;
  - 10,000-file, 128 MiB per-file and 512 MiB total uncompressed limits;
  - per-file SHA-256 and canonical sorted inventory digest;
  - strict schema-v1 provenance validation;
  - deterministic tar.gz writer and exact-archive SHA-256 sidecar;
  - exclusive output creation and refusal to overwrite.
- Added build_skills_package.py, which records the exact Git commit, source date epoch and optional source ref.
- Strengthened check_skills_package.py:
  - requires and verifies BUILD_PROVENANCE.json;
  - verifies each file path, size and SHA-256 plus payload totals/digest;
  - checks README and newest CHANGELOG version headings;
  - verifies the first three default prompts verbatim and in order;
  - rejects bytecode/cache/symlinks/special files;
  - bounds decompression of the pinned Mojang Samples index to 64 MiB.
- Added test_build_skills_package.py and expanded test_check_skills_package.py.
- Updated package-integrity skill instructions, README maintenance workflow, CI step label and GITHUB_SYNC_NOTES.md.
