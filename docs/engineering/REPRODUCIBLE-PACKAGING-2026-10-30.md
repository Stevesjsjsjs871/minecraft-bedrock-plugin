## Implemented

Added a deterministic archive builder that reads only committed Git tree objects (git ls-tree and git cat-file), rather than walking the working directory. Therefore, untracked bytecode created by test execution cannot leak into the candidate package.

The builder:
- packages the declared plugin payload: required root manifests/docs plus server/ and skills/;
- rejects tracked bytecode/cache artifacts, symlinks, non-regular Git objects, unsafe paths and oversized payloads;
- validates SemVer, both manifests, identical non-empty prompt arrays, MCP config parity and referenced server script existence;
- creates a deterministic tar.gz with the exact source commit SHA and commit timestamp;
- embeds BUILD_PROVENANCE.json with sorted per-file SHA-256 and size records plus a canonical payload digest;
- writes a sidecar SHA-256 for the complete archive;
- uses atomic output replacement and rejects symlinked output path components;
- refuses to overwrite package source paths when output is placed inside the repository (only dist/ or artifacts/ are allowed).

BUILD_PROVENANCE.json excludes itself from the payload digest to avoid a self-reference cycle. The sidecar hashes the final archive including the provenance document.

## Limitations

- The existing Plugin Creator 1.4.0 release still contains the two bytecode files; this source-side PR does not modify that release.
- The builder packages the checked-out Git tree. On PR runs that is the merge tree used by CI; on main pushes it is the exact pushed commit.
- Minecraft import/runtime, Creator Tools CLI, Blockbench interoperability, Windows and macOS packaging are not verified here.
- No Plugin Creator release was created or updated.
